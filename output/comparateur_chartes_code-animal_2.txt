Association Code Animal
Charte Code Animal pour transformer le zoo de Montpellier en refuge
La charte proposée par Code Animal en faveur de la transformation du zoo du Lunaret en refuge pour animaux sauvages. Les refuges permettent notamment d’accueillir des animaux saisis, abandonnés ou issus de structures fermées, comme les cirques.
